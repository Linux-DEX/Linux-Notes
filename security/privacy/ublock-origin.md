# uBlock Origin

uBlock Origin blocks ads and trackers inside the browser. The Arch package installs it as a system extension for Firefox. Restart Firefox after installing. It shows up under Add-ons.

```bash
$ sudo pacman -S firefox-ublock-origin
```

The extension has its own dashboard in the browser. The package does not add a terminal command. Updating it is a normal `pacman -Syu`.
