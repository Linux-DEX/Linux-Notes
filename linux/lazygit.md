# lazygit

lazygit is a terminal UI for the Git repository in the current directory. The commands underneath are the ones in `linux/git.md`.

```bash
$ sudo pacman -S lazygit
$ lazygit
```

| Key | Effect |
| --- | ------ |
| `?` | Keybindings for the panel you are in |
| `q` | Quit |
| space | Stage or unstage the selected file |
| `c` | Commit the staged files |
| `[` and `]` | Previous and next panel |

`?` is the full list. Push, pull, and branch keys are in that menu, and they differ by panel.
