# RANGER (File Manager)
Terminal file manager

```bash
$ ranger
```

| Keys    | Description                |
| ------- | -------------------------- |
| h j k l | back , down , up , forward |
| gg      | go to the top              |
| i       | preview file               |
| r       | open file                  |
| zh      | view hidden file           |
| cw      | rename current file        |
| yy      | (yank) copyfile            |
| dd      | cut file                   |
| pp      | past file                  |
| u       | undo                       |
| z       | changing settings          |
| dD      | delete file                |
