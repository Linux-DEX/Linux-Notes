# Emacs
Org mode is for keeping hierarchal notes (and more) in Emacs.

## Heading 
```emacs
 *             heading1
 **            heading2
 ***           heading3
 ****          heading4
 *****         heading5
 ******        heading6
```

## Lists
```emacs
    1. 
    2. 

    -  
    - 

    + 
    + 
```

## Inline Style
```emacs
    *bold*
    /italic/
    _underline_
    =verbatim=
    ~code~
    +strike-through+
```

## Attach file and image
+ Inline image
```emacs
 [[/path/to/image]]
```

+ Add link
```emacs
 [[link/to/webpage][text]]
```

+ link file
```emacs
 [[file:/media/xander/Backup/Hacker/Linux/Linux.org][Linux Notes]]
```
